# Wrist 3D Reconstruction Demo (1mm Accuracy)

Isolated project directory for reconstructing a 3D Mannequin Hand model (.stl) from 2D AP and Lateral images with direct manual measurement anchoring.

## Steps
- **Step 1**: Manual Measurement Anchoring (1mm metric scale lock)
- **Step 2**: 2D Contour & Silhouette Extraction
- **Step 3**: Mannequin Template Morphing & 3D Reconstruction
- **Step 4**: Virtual Caliper Verification & Manifold STL Export
